Bounty: https://make.fun/bounty/u-donrulezz-museum-of-the-year-3000-b727a0bb

One line: the museum label a museum in the year 3000 puts beside an
ordinary object from today — a QR code printed on a restaurant table.

`main.py` (Python 3 standard library only) writes the label to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. It is deterministic: the same fixed
line on every run.
